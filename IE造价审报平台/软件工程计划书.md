# IE工程造价审报自动生成平台系统
## 软件工程计划书

---

## 一、项目概述

### 1.1 项目背景
工程造价评审工作中，需要从Excel工程量清单中提取数据，填充到Word评审报告模板中，工作量大且易出错。本项目旨在开发一个Web平台，实现评审报告的自动化生成。

### 1.2 项目目标
- 实现Excel数据自动解析和提取
- 支持多种Word模板格式
- 提供可视化的数据预览和编辑界面
- 自动生成标准化的评审报告
- 支持项目管理和历史记录查询

### 1.3 目标用户
- 工程造价咨询公司
- 建设项目评审机构
- 施工单位预算部门

## 二、功能需求

### 2.1 核心功能模块

#### 2.1.1 项目管理模块
- 创建/编辑/删除工程项目
- 项目基本信息管理（项目名称、建设单位、工程类型等）
- 项目状态跟踪（草稿、审核中、已完成）
- 项目数据导入导出

#### 2.1.2 数据导入模块
- Excel文件上传和解析
- 自动识别工程类型（道路/排水/交安/桥涵/照明/电力/通信）
- 数据校验和错误提示
- 支持批量导入多个Excel文件
- 数据预览和人工修正

#### 2.1.3 模板管理模块
- Word模板上传和管理
- 模板字段映射配置
- 模板变量定义（如：{项目名称}、{送审金额}等）
- 模板预览和测试

#### 2.1.4 报告生成模块
- 基于模板自动生成评审报告
- 支持多种报告类型（预算评审、结算评审等）
- 数据填充和格式化
- 报告预览
- 导出为Word/PDF格式

#### 2.1.5 历史记录模块
- 报告生成历史记录
- 版本管理和对比
- 数据备份和恢复
- 导出历史报告

### 2.2 辅助功能

#### 2.2.1 用户管理
- 用户注册/登录
- 权限管理（管理员/普通用户）
- 操作日志记录

#### 2.2.2 系统设置
- 系统参数配置
- 数据字典管理（工程类型、单位等）
- 备份策略设置

## 三、技术架构

### 3.1 技术栈选型

#### 前端技术
- **框架**: Vue 3 + TypeScript
- **UI组件库**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router
- **HTTP客户端**: Axios
- **文件上传**: vue-upload-component

#### 后端技术
- **框架**: Python Flask / FastAPI
- **数据库**: SQLite（开发）/ PostgreSQL（生产）
- **ORM**: SQLAlchemy
- **文件处理**: 
  - openpyxl（Excel处理）
  - python-docx（Word处理）
  - reportlab（PDF生成）
- **任务队列**: Celery + Redis（异步任务）
- **缓存**: Redis

#### 部署环境
- **Web服务器**: Nginx
- **应用服务器**: Gunicorn / Uvicorn
- **容器化**: Docker + Docker Compose
- **CI/CD**: GitHub Actions

### 3.3 数据库设计

#### 核心数据表

**projects（项目表）**
```sql
CREATE TABLE projects (
    id SERIAL PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    client_name VARCHAR(200),
    project_type VARCHAR(50),
    status VARCHAR(20) DEFAULT 'draft',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**excel_files（Excel文件表）**
```sql
CREATE TABLE excel_files (
    id SERIAL PRIMARY KEY,
    project_id INTEGER REFERENCES projects(id),
    file_name VARCHAR(255),
    file_path VARCHAR(500),
    engineering_type VARCHAR(50),
    upload_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**excel_data（Excel数据表）**
```sql
CREATE TABLE excel_data (
    id SERIAL PRIMARY KEY,
    file_id INTEGER REFERENCES excel_files(id),
    item_name VARCHAR(500),
    submitted_qty DECIMAL(15,2),
    submitted_price DECIMAL(15,2),
    submitted_total DECIMAL(15,2),
    audited_qty DECIMAL(15,2),
    audited_price DECIMAL(15,2),
    audited_total DECIMAL(15,2),
    adjustment DECIMAL(15,2),
    row_index INTEGER
);
```

**templates（模板表）**
```sql
CREATE TABLE templates (
    id SERIAL PRIMARY KEY,
    name VARCHAR(200),
    template_type VARCHAR(50),
    file_path VARCHAR(500),
    variables JSONB,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**reports（报告表）**
```sql
CREATE TABLE reports (
    id SERIAL PRIMARY KEY,
    project_id INTEGER REFERENCES projects(id),
    template_id INTEGER REFERENCES templates(id),
    file_name VARCHAR(255),
    file_path VARCHAR(500),
    status VARCHAR(20) DEFAULT 'generated',
    generated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 五、模块设计

### 5.1 后端API设计

#### 项目管理API
```
POST   /api/projects              创建项目
GET    /api/projects              获取项目列表
GET    /api/projects/{id}         获取项目详情
PUT    /api/projects/{id}         更新项目
DELETE /api/projects/{id}         删除项目
```

#### 数据导入API
```
POST   /api/projects/{id}/upload  上传Excel文件
GET    /api/projects/{id}/data    获取项目数据
PUT    /api/projects/{id}/data    更新项目数据
POST   /api/projects/{id}/validate 数据校验
```

#### 模板管理API
```
POST   /api/templates             上传模板
GET    /api/templates             获取模板列表
GET    /api/templates/{id}        获取模板详情
PUT    /api/templates/{id}        更新模板
DELETE /api/templates/{id}        删除模板
```

#### 报告生成API
```
POST   /api/projects/{id}/generate 生成报告
GET    /api/projects/{id}/reports  获取报告列表
GET    /api/reports/{id}/download  下载报告
GET    /api/reports/{id}/preview   预览报告
```

### 5.2 前端页面设计

#### 主要页面
1. **登录页** - 用户认证
2. **仪表盘** - 项目概览、统计数据
3. **项目管理页** - 项目列表、创建/编辑项目
4. **数据导入页** - Excel上传、数据预览、数据编辑
5. **模板管理页** - 模板列表、上传模板、配置映射
6. **报告生成页** - 选择模板、生成报告、预览下载
7. **历史记录页** - 报告历史、版本对比
8. **系统设置页** - 参数配置、用户管理

### 5.3 核心业务流程

```
1. 用户创建项目
   ↓
2. 上传Excel文件（支持多个）
   ↓
3. 系统解析Excel数据
   ↓
4. 数据预览和校验
   ↓
5. 用户确认/修正数据
   ↓
6. 选择报告模板
   ↓
7. 系统生成报告
   ↓
8. 用户预览报告
   ↓
9. 下载/导出报告
```
